
# BMI Calculator  

## Project Description  

This repository contains two implementations of a Body Mass Index (BMI) calculator:  

1. **For Beginners**:  
   A command-line BMI calculator built using Python. It prompts users to input their weight (in kilograms) and height (in meters), calculates the BMI, and categorizes it based on predefined ranges (e.g., underweight, normal weight, overweight). The BMI result and corresponding health category are displayed.  

2. **For Advanced Users**:  
   A graphical BMI calculator with a user-friendly interface (GUI) built using Python libraries like Tkinter or PyQt. This version includes features such as:  
   - Input fields for weight and height.  
   - Calculation and visualization of BMI results.  
   - Data storage for multiple users.  
   - Viewing historical data and analyzing BMI trends with statistical graphs.  

## Key Features and Concepts  

- **User Input Validation**: Ensures that weight and height inputs are valid and within reasonable ranges. Handles errors gracefully.  
- **BMI Calculation**: Accurate implementation of the BMI formula.  
- **Categorization**: Classifies BMI into categories (e.g., underweight, normal weight, overweight, obesity).  
- **Health Tips**: Provides health advice based on the BMI category.  
- **GUI Design (Advanced)**: Intuitive interface for better user experience.  
- **Data Storage (Advanced)**: Stores user data in files or a small database.  
- **Data Visualization (Advanced)**: Displays historical BMI data using graphs or charts.  
- **Error Handling (Advanced)**: Handles data storage/retrieval issues efficiently.  
- **User Experience (Advanced)**: Ensures a responsive and user-friendly design with clear instructions and feedback.  

## How to Use  

1. Clone this repository:  
   ```bash  
   git clone <(https://github.com/Anam-Ali-2308/OasisTaskNo-2/tree/main)>  
   ```  

2. Navigate to the project directory:  
   ```bash  
   cd bmi-calculator  
   ```  

3. Run the appropriate script:  
   - For command-line version:  
     ```bash  
     python bmi_calculator_cli.py  
     ```  
   - For GUI version:  
     ```bash  
     python bmi_calculator_gui.py  
     ```
